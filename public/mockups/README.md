Coloca aqui os mockups com o nome `<design>-<cor>.<png|jpg|jpeg|webp>`,
usando os ids definidos em `src/lib/options.ts`:

- design-1-bordo.png, design-1-verde.png, design-1-branco.png
- design-2-bordo.png, design-2-verde.png, design-2-branco.png
- design-3-bordo.png, design-3-verde.png, design-3-branco.png

Versão finalista: o mesmo nome com `-finalista` no fim, por exemplo
`design-1-verde-finalista.png`. O botão "Versão finalista" da página de voto
só troca a imagem; o voto é o mesmo.
Se faltar a versão finalista de uma combinação, mostra-se a normal.
